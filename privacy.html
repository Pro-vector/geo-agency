Политика в отношении обработки персональных данных

1. Общие положения
Настоящая политика обработки персональных данных составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности, предпринимаемые GEOAI Studio (далее — Оператор).

2. Собираемые данные
Оператор может обрабатывать следующие персональные данные Пользователя:
— Имя, Фамилия;
— Номер телефона;
— Адрес электронной почты (e-mail);
— Обезличенные данные о посетителях (в т.ч. файлы «cookie») с помощью сервисов интернет-статистики.

3. Цели обработки данных
Цель обработки персональных данных Пользователя — предоставление доступа к сервисам, консультациям, подготовка коммерческих предложений и связь с клиентом по заявке с сайта geoai-studio.ru.

4. Локализация и хранение данных
Первичный сбор, систематизация и хранение персональных данных граждан Российской Федерации осуществляются на серверах, расположенных на территории Российской Федерации (ООО «Таймвэб», г. Санкт-Петербург).

5. Заключительные положения
Пользователь может получить любые разъяснения по вопросам обработки своих персональных данных, обратившись к Оператору по электронной почте или через форму обратной связи на сайте.
